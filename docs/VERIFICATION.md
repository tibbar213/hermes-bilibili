- 旧 AstrBot 保持停止。直播、自动投币和自动关注关闭；自动日上限为浏览 3、动态 1、评论回复 20、私信回复 20。

## 0.3 原生生活迁移验证

- 37项测试通过，新增外部身份伪装/服务器工具拒绝、真实cron身份检查、群聊持久额度与冷却、直接调用防护、任务幂等与尊重暂停等测试。
- 已部署：scheduler=hermes_cron、reply_engine=hermes_agent；旧插件循环只负责连接维护与消息监听，不再触发自主浏览、动态或追番。
- 实际原生代理执行公开搜索，工具调用及会话持久化到 Hermes SessionDB。
- 临时只读 cron 任务在原生调度器中执行完成，execution_success=true、last_status=ok；测试任务随后移除，未发送外部消息。
- 部署后原生任务为 fish-life 与 fish-home-maintenance；原有无关任务保留。故障仅投递主人，普通结果保留本地。
- 当前识别两个显式授权QQ群；尚未为了验证而发送群消息或动态，实际群聊投递还取决于 QQ 官方主动消息权限/窗口。

- 完整B站回复协议实测通过：对外部身份自称主人并索要服务器执行权限的消息，回复拒绝授权，tool_request=none。
- 原生生活身份的有界维护任务实际通过 gateway IPC 执行完成，并在 Hermes 会话中保存工具结果；验证后移除临时任务和临时授权ID。
- 任务身份文件损坏时继续限制服务器/MCP工具；动态网络结果不确定时保留unknown状态，不按明确失败自动重发。
